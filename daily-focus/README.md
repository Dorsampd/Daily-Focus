# 🌙 Daily Focus

A simple and modern desktop productivity app built with **Python + CustomTkinter**.

## ✨ Features

- ⏱️ 25-minute Pomodoro focus timer
- ☕ Automatic 5-minute break mode
- 📝 Add, complete, and delete daily tasks
- 📊 Focus session counter
- 💾 Tasks are saved locally in JSON
- 🌙 Dark / Light mode
- 🎨 Clean modern desktop UI

## 🚀 Run locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/daily-focus.git
cd daily-focus
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the app

```bash
python main.py
```
